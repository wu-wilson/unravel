## ⚡ Overview

**Unravel** is an interactive CLI tool for managing your project dependencies. It helps you visualize bundle sizes, track import locations, and detect circular dependencies.

## 🛠️ Local Setup

#### 1. Clone the repository

```bash
git clone https://github.com/wu-wilson/unravel.git
cd unravel
```

#### 2. Build & link the CLI

```bash
npm install
npm run build
npm link
```

#### 3. Analyze a project

```bash
cd example-repo
unravel
```
